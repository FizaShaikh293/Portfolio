# Bold Editorial Portfolio

## Direction
Keep the existing sand, charcoal, and rust editorial identity, but increase visual impact through scale, contrast, and stronger composition rather than adding clutter.

## Changes
- Make the opening nameplate more commanding with oversized type, bolder rules, and a more assertive rust/charcoal composition.
- Turn section titles into large editorial markers that visibly anchor every part of the page.
- Replace the narrow, timid content rhythm with wider layouts, stronger alternating bands, and deliberate asymmetry.
- Strengthen project, experience, technology, and certification entries with larger titles, high-contrast numbering, heavier dividers, and clearer interaction states.
- Keep the current content, links, CV download, Pac-Man navigation, and warm palette intact.
- Refine scroll reveals to feel decisive and polished while respecting reduced-motion preferences.

## Technical details
- Update shared visual tokens and reusable editorial utilities in the global stylesheet.
- Update the shared section heading so the stronger hierarchy carries across the full site.
- Adjust the main section components using the existing semantic color system and responsive breakpoints.
- Verify the page at desktop and mobile widths, then check the final build and browser console.
